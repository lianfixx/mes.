PARA ABRIR EL PROYECTO EN TU MAC
1. Instala Node.js 24 con npm si aún no lo tienes.
2. Descomprime el ZIP y abre la carpeta Mes en tu editor.
3. Abre una terminal dentro de esa carpeta y ejecuta, en orden:
   npm ci
   npm test
   npm run typecheck
   npm run build
   npm run dev
4. Abre la dirección local que aparezca en la terminal.

El código fuente requiere esos pasos para ejecutarse. La copia TXT sirve para
leer el código o compartirlo con Claude. El ZIP incluye package-lock.json.
